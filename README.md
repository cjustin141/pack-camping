# Full-Stack Camping App

A collaborative camping trip planner that helps groups organize their itinerary, decide what to pack, and keep track of who is bringing each item.

Instead of coordinating trip details across group chats and spreadsheets, participants share one plan with daily activities and a gear checklist.

## Planned features

- Create trips with dates, a destination, and trip notes.
- Invite participants and manage trip membership.
- Build a day-by-day itinerary.
- Maintain a reusable personal gear catalog.
- Add required gear to a trip and let participants claim quantities to bring.
- Track outstanding gear and packing progress without duplicate or excess claims.

## Project goals

Build practical experience in backend and full-stack development, with an emphasis on relational data modeling, API design, authorization, database transactions, concurrency, testing, and deployment.

## Proposed stack

React and TypeScript frontend, ASP.NET Core Web API backend, and PostgreSQL database. Docker Compose for local development and GitHub Actions for CI. AWS deployment is a later milestone.

The frontend, backend, and supporting documentation will live in one monorepo.
